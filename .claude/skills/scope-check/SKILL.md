# 범위 확인

## 언제 쓰나

- 새 기능이나 화면을 만들려 할 때
- 만들려는 것이 PRD.md 범위 안인지 밖인지 물을 때

## 무엇을 받나

만들려는 기능이나 화면 한 줄 설명

## 어떤 순서로 하나

1. PRD.md §3 비목표와 §4 사용자 흐름의 화면 8개를 읽는다.
2. 받은 설명을 비목표 9개와 화면 8개에 대조한다.
3. 판정한다.

## 무엇을 내놓나

판정 한 줄과 근거 한 줄.

- 판정: 범위 안 / 범위 밖
- 근거: 걸린 PRD.md 항목 번호(예: 비목표 6, §4 화면 8개 밖). 근거가 없으면 "PRD.md에 없음"이라고 쓴다.

## 지킬 것

- PRD.md 에 없는 내용은 지어내지 않는다.
- 파일은 고치지 않는다.
