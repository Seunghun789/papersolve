# 화면 만들 때 규칙

- 화면은 PRD.md §4 사용자 흐름의 웹 8개(홈 · 올리기 · 확인 · 묻기 · 그래프 · 대상 · 대시보드 · 자동화)다. 모바일 화면은 웹이 검증된 뒤 같은 흐름으로 만든다.
- 버튼 이름은 PRD.md §4에 적힌 글자 그대로 쓴다. 예: [읽기 시작], [맞아요], [하나씩 볼게요], [같은 칸], [등록], [같은 대상], [묶기], [바꾼 것 올리기], [적용], [이어 보기], [켜기], [홈으로], [확인할 것 N개], [직접 적기], [저장], [만들어 보기], [이번 주 요약 만들기], [나란히 보기], [👍].
- 사용자가 직접 바꾸는 설정은 바로 쓰지 않고 카드로 올린다. 카드에는 켜 둔 자동화·올린 지표가 어떻게 바뀌는지 미리 보여 준다.
- 화면 기준은 `idea/wireframe_v2.png`, 묻기 화면과 이동은 `idea/flow.md`.
- 화면 글에는 "스키마·온톨로지·엔티티·클래스·속성" 대신 "기록 종류·칸·대상·분류·정보·관계·같은 칸"을 쓴다. 숫자 옆에는 근거 기록(N줄)을 붙인다.
- 예/아니오 카드는 `app.py`의 `card()` 한 곳에서 그린다. 새 제안 종류도 여기에 더한다.
