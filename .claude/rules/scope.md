# 기능·도구를 더할 때 규칙

- PRD.md §3 비목표 1~9에 적힌 기능(돈의 흐름, 에이전트의 쓰기, 외부 어시스턴트 연결, 업종 규칙 미리 넣기, 여러 장 올리기, 로그인·권한, xlsx 내보내기·양식 출력, 모바일, 대상 합치기·나누기·지우기, 칸 이름·값의 종류 바꾸기, 지식그래프에서 점·선 직접 그리기·지우기, 기록 종류·칸·대상·분류 확정 되돌리기, 업무 흐름 직접 짜기)은 만들지 않는다.
- 업종·쓰임별 규칙(판정 기준, 재고 부족 기준, 쓰임별 홈 카드 등)을 코드에 고정하지 않는다. 기록 종류·칸·관계·지표·자동화는 AI 제안 → 사용자 확정(`proposals`)으로만 생긴다. 새 쓰임을 지원할 때는 코드 분기 대신 샘플을 넣어 같은 엔진으로 도는지 본다.
- 화면과 답에 보이는 숫자는 코드가 기록에서 센다. 표·지표·자동화·묻기·요약은 `core/engine.py`가, 대화로 만든 보기는 `engine.py`가 고른 기록으로 Vega-Lite가 센다. Claude 호출은 `core/llm.py`에만 두고, Claude는 숫자를 적거나 기록을 넣지 않는다.
- 라이브러리나 서비스를 새로 설치하거나 연결하기 전에, 답에 그 이름과 쓰려는 까닭을 적고 사용자가 답한 뒤에 설치한다.
