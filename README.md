# papersolve

### 무엇을 하는 서비스인가

손으로 적은 종이 사진이나 CSV를 올리면, AI가 표 구조(기록 종류와 칸), 대상(품목·설비·고객 등)과 그 정보, 칸과 분류 사이의 관계를 제안합니다. 사용자는 예/아니오로만 확정합니다. 확정한 지식 위에서 질문에 근거와 함께 답하고, 대시보드와 자동화로 할 일을 챙깁니다.

- 화면과 답에 보이는 숫자는 모두 코드가 기록에서 셉니다. AI는 구조와 이름을 제안하고 문장만 씁니다. 기록을 넣거나 바꾸지 않습니다.
- 숫자 옆에는 근거 기록이 붙고, 근거 기록의 줄을 누르면 원본 사진이 보입니다.
- 업종별 규칙을 미리 넣어 두지 않습니다. 규칙은 사용자가 확정한 관계와 자동화로만 생깁니다.

### 누구를 위한 것인가

종이·손글씨·엑셀로 기록하는 개인과 작은 조직입니다. 업종이 아니라 역할로 나눕니다.

| 역할 | 하는 일 |
|---|---|
| 현장에서 적는 사람 | 종이를 찍어 올리거나, 같은 칸으로 바로 적습니다 |
| 실무 담당 | 확인 카드에 답하고, 관계와 자동화를 확정하고, 기록에 대해 묻습니다 |
| 대표 | 홈의 "오늘 먼저 볼 것"과 대시보드를 봅니다 |

### 어떻게 쓰나

1. **계정 만들기**: 왼쪽 사이드바의 "새 계정 만들기"에 이름을 적고 [만들기]를 누릅니다. 이미 만든 계정은 "계정"에서 고릅니다. 계정마다 기록과 지식이 따로 쌓입니다.
2. **올리기**
   - [사진·CSV]: 사진이나 CSV를 끌어 놓고, "읽는 모델"을 고른 뒤 [읽기 시작]을 누릅니다.
   - [직접 적기]: 확정한 기록 종류를 고르고, 날짜와 칸을 채워 [저장]을 누릅니다.
3. **확인**: 왼쪽에 원본(사진, 또는 CSV 앞부분 8줄), 오른쪽에 카드가 보입니다.
   - 새 기록 종류: [아니요] · [하나씩 볼게요] · [맞아요]
   - 새 칸: [아니요] · [추가]
   - 같은 칸: [다른 칸] · [같은 칸]
   - 읽기 애매한 칸: [네, 맞아요], 또는 [아니요, 고칠게요]로 값을 고치고 [저장]
   - 다 보면 [홈으로]로 갑니다. [← 올리기로]로 돌아갈 수도 있습니다.
   - 아래 "최근 반영한 것"에서 대상 정보 값·별칭·칸의 단위·설명·다른 이름을 [되돌리기]로 반영 전으로 돌립니다. 되돌리기도 카드로 올라가고 [적용]을 눌러야 반영됩니다.
4. **대상**: 품목·설비·고객 같은 대상을 다룹니다.
   - 카드: "대상 등록"·"새 대상"·"같은 대상"·"대상 정보"·"대상 정보 값"·"분류 묶기"·"관계 정보"에 [등록] · [같은 대상] · [맞아요] · [바꾸기] · [묶기]로 답합니다.
   - 대상 표: 정보 값을 고치거나 새 대상을 적고 [바꾼 것 올리기]를 누릅니다.
   - "정보 더하기 · 별칭 · 묶기": [정보 더하기] · [별칭 더하기] · [하위 분류로 묶기] · [상위 분류 정하기]
   - "대상 사이 관계": 관계 정보 이름과 쌍마다 값을 넣고 [관계 정보 올리기]를 누릅니다.
   - 직접 바꾼 것은 모두 카드로 올라갑니다. 켜 둔 자동화와 올린 지표가 어떻게 바뀌는지 보고 [적용]을 눌러야 반영됩니다.
5. **지식그래프**: 기록 종류·칸·대상 분류와 관계를 그림으로 봅니다. 확정한 관계는 실선, 제안은 점선입니다.
   - [구조만] · [대상까지]로 보기를 바꿉니다.
   - "관계 제안" 카드에 기록에서 센 근거가 보입니다. [맞아요]를 누르면 실선이 됩니다.
   - 확정한 관계는 [끊기]로 지웁니다.
   - "이어져 있다고 생각하는 칸이 있나요?"에서 두 칸과 관계를 고르고 [이어 보기]를 누르면 제안 카드로 올라갑니다.
   - 점을 누르면 오른쪽에 그 점의 설정 칸이 열립니다. 대상 점은 정보 값([바꾼 것 올리기])과 [별칭 더하기], 대상 분류 점은 [정보 더하기]·[하위 분류로 묶기]·[상위 분류 정하기], 기록 종류 점은 [칸 더하기], 칸 점은 [단위·설명 올리기]·[다른 이름 더하기]입니다. 고친 것은 카드로 올라가고 [적용]을 눌러야 반영됩니다. 칸 이름과 값의 종류는 바꾸지 않습니다.
6. **대시보드**
   - "말로 만들기"에 보고 싶은 것을 적어 보냅니다(예: 일일 합격률 추이를 선 그래프로). 이어서 고칠 점을 말해도 되고, 미리보기가 맞으면 [올리기]를 누릅니다.
   - "추천 지표" 카드는 [올리기]로 올립니다. 올린 지표는 [내리기]로 뺍니다.
   - 확정한 기록 종류마다 "자동으로 만든 현황"이 보입니다.
7. **자동화**
   - "말로 만들기"에 챙길 일을 적어 보내고, 규칙과 지금 걸린 건수를 본 뒤 [켜기]를 누릅니다.
   - "반복 업무 제안" 카드도 [켜기]로 켭니다. 며칠째 기록이 없는 대상을 찾는 "N일 넘게 없음" 제안도 여기에 나옵니다.
   - 켜 둔 자동화는 [끄기]로 끄고, "꺼 둔 자동화"에서 [다시 켜기]로 다시 켭니다.
8. **홈**
   - "오늘 먼저 볼 것"에서 켜 둔 자동화마다 걸린 건수와 대상 이름을 봅니다. 확정한 의존·영향·대체 관계가 있으면 "이어서 볼 것"도 보입니다.
   - [확인할 것 N개]를 누르면 확인으로 갑니다.
   - [이번 주 요약 만들기]를 누르면 요약 문장과 문장마다 "근거 기록 N줄", "센 숫자"를 봅니다.
   - "쌓인 기록" 표의 줄을 누르면 원본 사진이 보입니다.
9. **묻기**
   - 질문을 적고 [묻기]를 누르거나 Enter를 칩니다. 답과 "근거 기록 N줄"이 보이고, 근거가 없으면 "기록에 없어요"라고 답합니다.
   - [나란히 보기]를 켜면 구조를 확정하기 전과 지금 지식의 답이 나란히 보입니다. 더 맞는 쪽의 [이 답이 맞아요]를 누릅니다.
10. 지식그래프·대상·대시보드·자동화에서는 제목 오른쪽의 [새로 추천받기]로 새 제안 카드를 받습니다.
