# 쓸 사람

| 항목 | 내용 |
|---|---|
| 누구인가 | 일상과 업무에서 종이·손글씨·엑셀로 기록하는 개인과 조직. 현장에서 적는 사람, 기록을 모아 챙기는 실무 담당, 먼저 볼 것만 보는 대표. 1인이면 한 사람이 모두 한다. |
| 언제 | 적은 종이를 엑셀에 옮겨 적을 때. 매일 같은 양식을 다시 적을 때. 양식이 바뀌어 지난 기록과 맞춰야 할 때. 쌓인 기록에서 오늘 챙길 것(기준을 넘은 값, 재고 부족, 이번 주 미팅, 며칠째 빠진 점검)을 찾을 때. 지난 기록을 물어보고 싶을 때. 대표가 한 주를 몇 줄로 보고 싶을 때. |
| 왜 | 옮겨 적는 데 시간이 들고, 오타가 나고, 칸이 밀린다. 기록에 구조가 없어서 통계·차트·질문·자동화를 매번 사람이 손으로 한다. 구조를 잡아 줄 사람(FDE: 고객 현장에서 데이터 구조를 잡아 주는 엔지니어)을 둘 수 없다. |
| 지금은 어떻게 | 종이에 적기 → 사무실에서 엑셀에 옮겨 적기 → 최대·최소를 다시 계산하고 차트를 고치기 → 오늘 챙길 것은 표를 뒤져서 찾기. 예: 제조 점검 담당은 매일 아침 점검표를 출력해 현장에서 적고 엑셀에 옮긴다. 유통 대표는 재고표를 보고 발주할 품목을 직접 고른다. 공인중개사는 수첩에서 이번 주 미팅을 찾는다. |
