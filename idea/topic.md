# 확정 주제

한 줄 정의 : 손으로 적은 종이를 찍으면, AI가 표 구조·대상·관계를 제안하고 사람이 예/아니오로 확정해 지식으로 쌓고, 그 지식 위에서 질문에 근거와 함께 답하고 업무를 챙기는 서비스.

- 쓰는 사람 : 일상과 업무에서 종이·손글씨·엑셀로 기록하는 개인과 조직. 업종으로 나누지 않는다. 예: 제조 설비 점검, 생산 검사, 영세 유통의 재고·발주, 공인중개사의 고객 요청 메모.
- 넣을 기능 : [scope.md](scope.md)의 넣을 기능 23개.
- 핵심 : 구조(기록 종류·칸·대상·대상 정보·분류·관계)는 AI와 규칙이 제안하고 사람이 확정한다. 사람이 직접 고친 설정과 말로 청한 지표·자동화도 같은 확정을 거친다. 확정한 관계와 기록 간격이 대시보드 지표와 자동화 규칙을 만들고, 확정한 칸으로는 종이 없이 바로 적는다. 숫자는 모두 기록에서 센다.
