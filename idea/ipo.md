# 넣으면 나온다

한 줄 : 손으로 적은 종이 사진(또는 CSV)을 넣으면 → AI가 칸을 읽고 표 구조·대상·관계를 제안하고, 사람이 예/아니오로 확정한 지식 위에서 질문에 근거와 함께 답하고, 대시보드와 자동화로 먼저 볼 것을 챙겨 준다.

- 입력 : 사진 1장 또는 CSV 1개, 또는 확정한 기록 종류의 칸에 직접 적은 기록 1개. 확인 카드에 대한 예/아니오 답과 틀린 값 고치기. 질문 한 줄. 이어져 있다고 생각하는 두 칸 고르기, 대상 정보 고치기·대상과 별칭·분류·관계 정보 더하기, 보고 싶은 것이나 챙길 일을 대화로 청하고 이어서 고치기(모두 제안 카드나 미리보기의 버튼으로 확정한다). 평가 모드에서 더 맞는 답 고르기.
- 처리 :
  1. 읽기 : 사진에서 표의 행마다 칸 이름과 값을 읽는다. 표가 아닌 메모는 한 장이 한 행이다. CSV는 값을 그대로 쓴다. 직접 적은 기록은 확정한 칸 이름으로 바로 들어간다.
  2. 구조 제안 : 값의 종류(숫자·글·날짜·고르는 값)는 규칙이 값을 보고 정하고, AI는 기록 종류·칸 이름·단위·칸이 가리키는 대상 분류·칸 사이 관계에 이름을 붙여 제안한다.
  3. 확인 : 처음 보는 종류, 새 칸, 이름만 다른 칸, 읽기 애매한 값, 칸 사이 관계, 처음 보거나 다르게 적힌 대상, 대상 정보가 바뀐 값만 묻는다. 답한 것은 다음부터 묻지 않는다.
  4. 지식 : 분류(품목 ⊃ 식품) → 대상(생수 500ml, 최소 재고 40, 별칭) → 기록(날짜별 한 행) 세 층과 관계가 계정마다 쌓인다. 대상마다 늘 같은 칸은 대상 정보로, 대상 쌍마다 늘 같은 칸은 관계 정보로 제안된다. 확정한 구조가 다음 읽기의 기준이 된다.
  5. 활용 : 확정한 관계에서 대시보드 지표와 자동화 규칙이(켜기 전에 지난 30일 기록으로 몇 번 걸렸을지 코드가 센다), 대상마다 기록이 들어오던 간격에서 빠진 기록 규칙이 제안된다. 사용자가 대화로 청하면 AI가 확정한 지식 안에서 청한 모양의 보기(그리는 방법만 짓고 기록은 서비스가 넣는다)나 자동화 규칙을 만든다. 질문에는 정해진 조회 도구로 기록을 찾아 답하고, 평가 모드에서는 구조를 확정하기 전 지식으로도 함께 답한다. 이번 주 요약은 코드가 센 숫자로 AI가 문장만 쓴다. 숫자는 모두 기록에서 센다.
- 출력 :
  - 확인 : 원본 사진(또는 파일 앞부분) 옆에 카드. "새 기록 종류"(종류 이름과 칸마다 값의 종류·상태(확인됨·확인할 것)), "새 칸", "같은 칸", "읽기 애매한 칸". 아래에 "대상" 카드(같은 대상은 두 표기의 기록 수와 묶이는 기록 N줄, [나중에])와 "관계 제안". 아래에 "최근 반영한 것"과 [되돌리기].
  - 올리기 : 직접 적기 입력 화면. 값의 종류가 입력 부품이 된다(날짜는 달력, 숫자는 숫자 칸과 지난 값, 고르는 값은 버튼, 대상은 목록).
  - 홈 : 맨 위 "오늘 먼저 볼 것"(걸린 것이 많은 자동화 2장까지 제목·걸린 건수·대상 이름·근거 N줄, 나머지는 접어 둠, 빠진 기록은 마지막 기록 날짜, 의존·영향·대체 관계로 이어진 "이어서 볼 것")과 "확인할 것" 카드. 이번 주 요약(합계·많이 나온 대상 3개·지난주 대비, 문장마다 근거 기록). 종류마다 쌓인 기록 표(줄을 누르면 원본 사진)와 추이 차트.
  - 묻기 : 예시 질문, "이렇게 찾았어요"(AI가 쓴 조회 조건), 답, "근거 기록 N줄" 표, 원본 사진, 전에 맞다고 고른 질문이면 "확인한 답". 평가 모드에서는 어느 쪽인지 가린 두 답이 나란히.
  - 지식그래프 : 기록 종류·칸·대상 분류·상위 분류·관계 그림(확정은 실선, 제안은 점선), [대상까지] 보기, "관계 제안" 카드, 확정한 관계 목록. 점을 누르면 오른쪽에 그 대상·분류·기록 종류·칸의 설정 칸(나가는 관계·들어오는 관계).
  - 대상 : 대상 카드(등록·같은 대상·대상 정보·값 바뀜·분류 묶기·관계 정보), 분류 목록, 분류마다 대상 표(고치기·더하기), 대상 사이 관계와 관계 정보.
  - 대시보드 : 자동으로 만든 현황(기록 수, 숫자 칸 추이), 올린 지표, "추천 지표" 카드(지금 값과 일주일 전 값), 말로 만들기 대화(미리보기 그림, 이어서 말할 예시 버튼). 숫자마다 근거 기록과 원본 사진.
  - 자동화 : "반복 업무 제안"·"빠진 기록" 카드(지금 걸린 것, 지난 30일이었다면 걸렸을 수와 근거 기록, 빠진 기록은 평소 간격), 말로 만들기 대화(규칙과 같은 시험 결과), 켜 둔 자동화와 걸린 기록, 꺼 둔 자동화.
- 모양 : 모아 보여 주는 화면과 묻고 답하는 화면.
- 화면 : 홈 · 올리기 · 확인 · 묻기 · 지식그래프 · 대상 · 대시보드 · 자동화(웹). 화면 기준은 [wireframe_v2.png](wireframe_v2.png), 묻기 화면과 이동은 [flow.md](flow.md).

## 쓰임별 예

엔진과 화면은 같다. 아래 구조와 규칙은 미리 넣어 둔 것이 아니라 AI가 제안하고 사용자가 확정해서 생기는 것의 예다.

| 쓰임 | 넣는 것 | AI가 제안하는 구조(예) | 확정한 관계에서 나오는 것(예) |
|---|---|---|---|
| 제조 설비 점검 | 일일 설비 점검표 사진, 점검 기록 CSV | 일일 설비 점검: 설비(대상) · 점검 항목 · 기준 · 측정 온도(℃) · 합격여부 · 담당자 | 기준 → 측정 온도(최대 기준) → 자동화 "측정 온도 초과", 지표 "초과 건수" |
| 제조 생산관리 | 일일 검사 기록표 사진, 검사 CSV | 일일 검사 기록: 제품(대상) · 로트번호 · 치수(mm) · 무게(g) · 외관 · 판정 · 검사자 | 지표 "불합격 건수", 자동화 "최근 7일 불합격 판정". 기록 간격에서 자동화 "일일 검사 기록 2일 넘게 없음". 대화로 만든 "제품별 일일 합격률 추이" 선 그래프 |
| 영세 유통 | 재고·발주 점검표 사진, 재고 CSV | 재고 점검: 품목(대상) · 현재 재고 · 발주 요청 · 입고 · 거래처(대상). 품목 정보: 최소 재고. 품목 ⊃ 식품·소모품. 품목—거래처 관계(정보: 단가) | 품목.최소 재고 → 현재 재고(최소 기준) → 자동화 "현재 재고 부족", 지표 "부족 건수"·"현재 재고와 최소 재고" 추이. 말로 청한 지표 "이번 주 입고 합계" |
| 공인중개사 | 고객 요청 메모 사진, 상담 CSV | 고객 요청: 고객(대상) · 지역 · 예산(만원) · 요청 · 미팅(날짜) · 상태 · 연락처 | 자동화 "이번 주 미팅"(미팅이 7일 안), "연락 대기 고객". 대화로 만든 "미팅 예약 달력"(주×요일) |
